## 📋 Sobre o projeto

Calculadora interativa construída sem bibliotecas externas. O projeto foca no tratamento de eventos, validação de entrada e organização do código em funções modulares — conceitos fundamentais da programação frontend.

---

## ✨ Funcionalidades

- ➕➖✖️➗ Operações básicas: adição, subtração, multiplicação e divisão
- 🔢 Suporte a números decimais
- ⛓️ Operações encadeadas (ex: 5 + 3 × 2)
- 🔄 Botão de limpar (C) e apagar último dígito (⌫)
- ⌨️ Suporte a teclado numérico
- 🚫 Tratamento de erros (divisão por zero)
- 📱 Layout responsivo

---

## 🧠 Conceitos aplicados

| Conceito | Onde foi usado |
|---|---|
| Tratamento de eventos | `addEventListener` nos botões e no teclado |
| Validação de entrada | Impede múltiplos operadores e pontos decimais |
| Funções modulares | Cada operação em sua própria função |
| Lógica condicional | Controle do fluxo de cálculo |
| Manipulação de DOM | Atualização do display em tempo real |
| `parseFloat` | Conversão de string para número antes do cálculo |
